# MediaLink 下载器 v3.0.6

本次更新合并 v3.0.5 的抖音图文路由修复，并处理完整代码审查中的 7 项问题。

## 更新内容

- 抖音图文通过 `/video/` 分享时自动识别并转入图文解析。
- 图文图片、视频片段和配乐在保存前解码校验；损坏素材刷新地址重试，仍失败则不发布成品。
- 修复“最高可用”被旧低画质记录拦截的问题，下载时仍重新获取实际最高档位。
- B 站短链、播放解析、备用提取和扫码流程贯穿取消信号，取消后不再开始后续请求。
- 已确认过期的登录独立更新，即使视频随后解析失败也正确显示未登录。
- 封面传输异常不再使整条 B 站视频解析失败。
- 构建成功或失败后恢复终端环境与工作目录，打包前运行回归测试。
- 通用错误提供平台中立的 `ML-` 编号，诊断日志不保存异常正文、cookies 或签名地址。
- 兼容 FFmpeg 的动画 WebP 标识；选择 PNG 时仍保留 GIF、动画 WebP 的完整动画。

## 下载文件

- `MediaLinkDownloader-v3.0.6-win-x64.zip`：首次使用请选择完整便携包，解压后运行 `MediaLinkDownloader.exe`，保留 `_internal`、`runtime` 等配套目录。
- `MediaLinkDownloader.exe`：相同版本完整目录内的主程序副本，不能独立运行，不能替代完整便携包。
- `MediaLinkDownloader-v3.0.6-source.zip`：对应提交的项目源码、测试、构建与审查文件。
- `MediaLinkDownloader-v3.0.6-third-party-sources.zip`：第三方源码、版本清单与许可材料。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

## 验证结果

61 项自动测试全部通过。真实验证了用户提供的抖音五图作品、图片与视频混合作品、B 站 MP3 下载，以及队列和历史；MP4/MP3 成品经过严格解码。新 ZIP 全新解压启动、旧数据库迁移、构建环境恢复通过。

真实扫码和会员权限未在这次发布中重新验证；相关状态与取消行为使用临时会话、Qt 主窗口和模拟响应测试。

## 升级与数据

先退出旧版，把旧版 `data` 复制到新版目录后启动，保留设置、历史和同一 Windows 用户的加密会话。公开附件不含用户数据。

素材完整性校验会增加处理时间，长片段尤为明显，期间可以取消。实况照片仍以同序号静帧和短片分别保存，素材模式的配乐保留源格式。

详细说明见 [修复与验收记录](../reviews/v3.0.6-fixes.md)。
