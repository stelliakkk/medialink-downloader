# B 站视频下载器 · 第一版计划

## 产品范围

- 支持普通投稿的 `bilibili.com/video/` 长链接、`b23.tv` 短链以及链接中的 `?p=`。显示封面、作者、时长和分 P，保留用户指定的分 P。
- 游客可以直接解析和下载。窗口内提供手机 B 站扫码登录、二维码刷新、登录状态和退出入口。仅在本机以 Windows DPAPI 保存 B 站会话。
- 以平台实际返回的完整媒体轨道为准。默认选当前最高可用画质，区分同分辨率的画质档位。保留手选档位，媒体地址失效时重新解析同档位。
- 输出带声 MP4、仅 MP3、MP4 + MP3。MP4 直接封装原轨道，MP3 从音轨转换。支持选择目录、进度、取消、重试和定位文件。
- 首版支持普通投稿和单任务下载。合集批量下载、直播、番剧、课程和互动视频留待后续讨论。

## 界面

使用深蓝灰底色、蓝色主操作和薄荷色状态提示。上方输入链接，中间左侧查看视频和分 P，右侧确认画质、输出和保存位置，下方显示实际下载阶段。空状态用程序绘制的图形，解析后换成视频封面。桌面窗口支持缩放，控件可通过键盘操作。

## 结构与步骤

1. 验证匿名画质、扫码接口和封装工具。对照 yt-dlp 的 B 站解析方式，优先复用已跑通的 B 站网页接口，按实际响应决定是否需要通用提取器。将平台依赖集中在 `platform.py` 和 `auth.py`。
2. 用 `models.py` 表达投稿、分 P、画质、轨道和输出。`download.py` 负责传输、媒体地址刷新、FFmpeg 封装和校验。临时文件与成品放在同一目标盘，验证后才使用最终文件名。
3. 用 `storage.py` 管理本机设置和登录状态，`workers.py` 管理后台任务。`ui/` 只负责界面与操作，保存进度、取消和错误反馈能覆盖解析、下载与转换阶段。
4. 用 PySide6 构建窗口，验证空状态、解析结果、多分 P、登录窗和不同窗口大小。用 PyInstaller 生成 Windows x64 便携包，随包提供 FFmpeg 和 FFprobe 及其来源说明。

## 验收

- 用 `BV1eknB6DE37` 真实解析、手选一个可用画质，输出 MP4 和 MP3。核对分辨率、时长、音轨和完整解码。另验短链及多分 P。
- 验证二维码生成和轮询、会话加密读写、登录失效后切回游客。真实扫码确认需要用户在手机端操作，记录实测覆盖范围。
- 验证取消和重试、临时地址过期、同名文件、路径含中文、仅 MP3 及画质手选规则。检查界面预览和打包程序启动。

## 第一版实测记录

- 直接调用 B 站网页接口取得游客档位。对于网页接口未返回的普通 720P／1080P 档位，补查 yt-dlp 提取器返回的完整轨道，并使用平台提供的备用媒体地址。
- Windows 窗口用样片完成 1080P 高清与 MP3 同时下载。FFmpeg 完整解码通过，MP4 为 1920 × 1080 并含 AAC，MP3 为 320 kbps。
- 实测短链跳转、长链接指定第 2 P、切换到第 1 P、中文路径、仅 MP3 和同名序号。模拟媒体地址失效后所选档位消失的场景，确认任务报错且没有降档写出文件。取消后临时目录清理通过。
- 真实二维码生成、未扫码轮询和取消通过，DPAPI 用测试值验证了加密存取。手机扫码确认及登录后的会员档位仍需用真实账号实测。
